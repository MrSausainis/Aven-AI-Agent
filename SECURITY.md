# Security Policy

Report vulnerabilities privately through GitHub when available:
https://github.com/MrSausainis/Aven-AI-Agent/security/advisories/new

Do not post secrets, tokens, personal data, exploit details, or an unpatched vulnerability in a public issue.

Current installers are unsigned. Use only the installer from the official Releases page. Production code signing and a signed/hash-verified update chain are release-readiness items.
