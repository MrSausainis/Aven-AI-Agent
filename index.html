What it actually does

Useful when it can act, quiet when it has nothing to show.

The core experience is deliberately small: talk or type, let A.V.E.N. handle the task, then get your screen back.

Voice + chat

Use the wake word for hands-free commands or open the full chat window for longer conversations. Conversation history and long-term memory are kept as separate systems.

CORE

Desktop control

Launch and close apps, work with windows and files, set timers, inspect system state, and use guarded actions that ask before doing something risky.

WINDOWS

Dynamic Island

A compact overlay shows only relevant state such as listening, media, timers and action results. It supports multi-monitor setups without becoming a second chat window.

OVERLAY

Cloud or local AI

Use cloud inference for convenience, or opt into local AI on your own hardware. Local models are not bundled with the installer and download only when you choose them.

YOUR CHOICE

Media + productivity

Spotify playback controls are built in, while optional plan features can add Office automation, streamer tools and other integrations.

Before you download

The things worth knowing before you install it.

Requirements and setup

Windows 10 or 11. A.V.E.N. is a Windows desktop application.
The installer is lightweight. Local AI model files are separate and are not downloaded unless you enable Local AI.
Cloud AI needs your own API key. Groq is the current recommended setup; keys are configured inside A.V.E.N., not on this website.
Local AI benefits from a capable GPU. It is optional, so it does not affect normal installation.

Accounts, data and payment

You can try the app without an account. An account is used for plan access, account settings and synced appearance preferences.
Your AI provider usage is yours. A.V.E.N. does not bundle hidden shared API usage into the installer.
Paid plans are optional. They unlock additional tools and plan features; checkout is handled by Stripe.
Current builds are not code-signed. Windows SmartScreen may warn the first time you run the installer.
Installer source: official GitHub release for this repository. Avoid copies hosted elsewhere.
