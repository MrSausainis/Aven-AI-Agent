# A.V.E.N.

A Windows desktop AI assistant — a small always-on overlay for voice, timers, and game widgets, plus a full chat window when you need one.

**[⬇ Download for Windows](https://github.com/MrSausainis/Aven-AI-Agent/releases/latest/download/AVEN-Setup.exe)** — no Python required, just run the installer.

Live page: **https://mrsausainis.github.io/Aven-AI-Agent/**

## What it does

- A pill-shaped overlay that shows what's playing, an active timer, or that it's listening — and collapses to a dot the moment there's nothing to say
- Voice control — in the cloud for speed, or fully local on your own GPU if you'd rather nothing leave your machine
- Game widgets that only show up when relevant (a CS2 match clock, a notes checklist you can star)
- Five visual themes, each with its own animation character, not just a repainted accent color

## Requirements

Windows 10 or 11. An SSD is recommended.
