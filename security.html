Security

Security controls, responsible disclosure and current limitations for the AvenAI website and Windows downloads.

Last updated: 29 September 2026
PrivacyTermsRefundsTrackingSecurityAccessibility

Security model

Frontend secretsThe site uses a Supabase publishable key designed for browser use. Service-role credentials and Stripe secrets stay server-side.
Database authorizationSupabase Row Level Security is enabled on the public account tables. Profiles and entitlements are owner-readable; reviews are public-readable but owner-writable; the tier catalogue is intentionally public-readable.
PaymentsCheckout is created server-side for an authenticated user and only server-approved plan identifiers are accepted. Stripe webhook signatures are verified before entitlement changes.
Browser securityPages use a Content Security Policy, the account dependency is version-pinned, and public review text is escaped rather than trusted as HTML.

Windows download security

Official installers are distributed from this repository's GitHub Releases page. Current builds are not code-signed, so Windows SmartScreen may warn. Code signing and a signed/hash-verified update chain remain release-readiness items.

Responsible disclosure

If you found a vulnerability, prefer GitHub's private reporting flow: report a vulnerability privately. Do not publish tokens, personal data or exploit details in a public issue.
